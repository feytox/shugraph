## Описание

После записи события graph-api находит группы первой схемы по правилам SRD (`docs/schemes/`) и сохраняет их. Риск считается в T-5.

## Решение

- [ ] Группа создаётся, когда набран минимум правила, и дополняется новыми событиями, пока не заморожена (SRD-9)
- [ ] Заполнены `group_members`, `group_events`, `first_event_at`, `last_event_at`, `accounts_count`, `total_amount`
- [ ] События замороженной группы не засчитываются в новую (SRD-10)
- [ ] Пороги в конфиге graph-api

## Тест-кейсы

1. Сценарий схемы из T-2: одна группа, состав совпадает с ожидаемым ответом.
2. Сценарий без мошенничества: групп нет.
3. Повторный прогон того же сценария на пустой БД даёт ту же группу.
