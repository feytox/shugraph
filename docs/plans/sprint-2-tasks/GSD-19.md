## Описание

graph-api принимает события по контракту (GSD-14), сохраняет их по модели из `docs/entities.md` и отсекает повторы.

## Решение

- [ ] Ручки приёма входа и перевода
- [ ] Битое событие (`docs/input-events.md`) отклоняется понятной ошибкой
- [ ] Повторы по контракту: новое событие 201, идентичный повтор 204, тот же `event_id` с другими полями 409

## Тест-кейсы

1. Перевод между двумя новыми счетами создаёт двух клиентов, два счёта и событие.
2. Вход с уже известного устройства не создаёт новое устройство.
3. Битое событие и конфликт по `event_id` ничего не пишут в БД.
4. Повторная отправка того же события не создаёт вторую запись.
