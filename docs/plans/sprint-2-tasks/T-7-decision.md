## Описание

Ручка решения по группе из контракта (GSD-14) работает по Ф6 из `docs/features.md`. Сборка групп для неё не нужна: в тестах группу можно вставить в БД напрямую.

## Решение

- [ ] Решение меняет статус группы, сохраняет комментарий и `decided_at` и замораживает группу
- [ ] Решение принимается только по новой группе
- [ ] Ответы по кодам из контракта

## Тест-кейсы

1. Подтверждение новой группы с комментарием: статус `approved`, группа заморожена, `decided_at` и комментарий сохранены.
2. Отклонение: то же со статусом `declined`.
3. Без комментария: 422, в БД ничего не меняется.
4. Повторное решение по той же группе: 409.
5. Несуществующая группа: 404.
