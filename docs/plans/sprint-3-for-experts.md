# План на декабрь

## Что есть сейчас

- Схема "Одно устройство на толпу" проходит весь путь на prod: сценарий, группа в списке, граф, карточка с причинами риска, решение аналитика.
- Повторная доставка события не создаёт второе, а повторный запуск на тех же данных даёт тот же результат.
- Для остальных трёх схем готовы сценарии и тексты карточек.
- Сайт открывается по ссылке без входа и без HTTPS.

## Что будет к концу декабря

- Система находит все четыре схемы, и у каждой работает тот же путь до решения аналитика.
- Вход по логину и паролю. Учётки заводим сами, регистрации нет.
- Сайт работает по HTTPS.
- В админке можно запустить сценарий и очистить данные за период, чтобы перед показом начинать с чистой БД.

## По вашим советам

- У решения по группе видно, кто из аналитиков его принял: делаем вместе со входом.
- Сборку групп разделим по схемам, у каждой схемы своя блокировка. Если успеем, события будут доходить до схем через брокер сообщений (скорее всего Kafka), и схемы будут обрабатываться параллельно.
- Если успеем, соберём логи и метрики prod в VictoriaLogs и VictoriaMetrics и выведем их на дашборды в Grafana.
- Планировщик, который удаляет старые группы, делать не будем. Если удалить события, их повторная доставка создаст их заново, а система должна отсекать такие дубли. Данные чистим вручную из админки перед показом.

## По неделям

- до 04.12: HTTPS, сборка групп разделена по схемам;
- до 11.12: находим схему "Один адрес на толпу", админка запускает сценарии;
- до 18.12: находим быстрые цепочки и кольца, работают вход и очистка данных, весь путь всех схем проверяем на prod;
- до 27.12: запас: логи и метрики, брокер сообщений.

## Что не входит

- Повтор отрезка времени, фильтры в списке групп.
- Регистрация и разделение данных между аналитиками: все аналитики видят одни и те же данные.
- Новый дизайн интерфейса.
