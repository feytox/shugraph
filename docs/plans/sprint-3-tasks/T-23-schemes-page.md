## Описание

В интерфейсе аналитика страница, где описаны четыре схемы, которые ищет система: что это за мошенничество, как оно выглядит на графе, по какому правилу мы его находим и из чего складывается риск. На защите по ней покажем, что именно ищет система. Тексты берём из `docs/schemes/`, к API страница не обращается.

## Решение

- [ ] Страница по адресу `/schemes`, в шапке ссылка "Схемы"
- [ ] Для каждой схемы название из `docs/schemes/README.md`, 2-3 предложения о том, что это за мошенничество, и правило обнаружения из раздела SRD её файла в `docs/schemes/`
- [ ] Картинка схемы - SVG, экспортированный из mermaid-диаграммы в файле схемы и сохранённый в приложении. Mermaid в браузере не подключаем
- [ ] Слагаемые риска схемы таблицей из `docs/schemes/risk.md`: тип схемы, скорость, масштаб, с баллами
- [ ] Страница собрана из компонентов Mantine по правилам `frontend/AGENTS.md`, тексты лежат в коде страницы
- [ ] Тест vitest: на странице четыре схемы с названиями
- [ ] Проверено в браузере, скриншот в PR

## Не входит

Правка `docs/schemes/`, пороги из конфига graph-api, интерактивные схемы.
