## Описание

graph-api сохраняет событие и сразу отвечает, а группы собирают обработчики схем, каждый читает события из брокера сам и параллельно с другими. Если задача не влита до 25.12, переносим её на после защиты.

## Решение

- [ ] Событие попадает в брокер через transactional outbox, ответы 201/204/409 не меняются
- [ ] У каждой схемы свой обработчик, порядок событий внутри схемы сохраняется
- [ ] Повторный прогон сценария даёт тот же результат, интеграционные тесты схем проходят
- [ ] Очистка БД учитывает события, которые ещё не обработаны
