## Описание

Карточка группы следует шаблонам из GSD-51 и показывает объяснение для схем "адрес", "цепочка" и "кольцо" так же, как сейчас для фермы. Числа карточка берёт из `features` и `risk_parts` в ответе (GSD-47), а не считает сама. Задача делается на моках и не ждёт задач схем.

## Решение

- [ ] Карточка фермы совпадает с `docs/cards/device-farm.md` после GSD-51: подписи плашек, строки таблицы "Из чего риск", свёрнутое и раскрытое "Что произошло"
- [ ] Подсчёт клиентов по `logins` (`farmClients.ts`) удалён, число берётся из `features.farm.clients_count`
- [ ] В `src/features/group-card/` компоненты `AddressExplanation`, `ChainExplanation`, `RingExplanation` по образцу `FarmExplanation.tsx`. Тексты и подписи дословно из `docs/cards/shared-address.md`, `fast-chain.md`, `ring.md`, числа только из `features` и `risk_parts`
- [ ] `GroupCard` выбирает объяснение по `scheme`, другие части карточки не меняются
- [ ] Моки MSW отдают по группе каждой схемы с числами из эталонных примеров в `docs/cards/`
- [ ] Тесты vitest: для каждого эталонного примера из `docs/cards/` текст карточки совпадает с ожидаемым
- [ ] Карточка каждой схемы проверена в браузере на моках, скриншоты в PR. На настоящих данных карточки новых схем проверяет приёмка схем (T-15) и T-16

## Не входит

Вид графа новых схем, изменения бэкенда, новые тексты карточек: тексты меняет только GSD-51.

## Тест-кейсы

1. На моках карточка каждой из четырёх схем показывает текст из её эталонного примера в `docs/cards/`.
