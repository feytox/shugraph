## Описание

У решения по группе хранится, кто его принял, а фронт может узнать текущего пользователя. Кто пользователь, graph-api берёт из заголовков `Remote-User`, `Remote-Name`, `Remote-Groups`, которые ставит Authelia; свою проверку пароля не делаем. Начинать можно сразу: в тестах заголовки ставятся вручную.

## Решение

- [ ] Ручка решения записывает логин и имя из заголовков вместе с решением, без `Remote-User` отвечает 401
- [ ] Карточка и список групп отдают, кто и когда принял решение
- [ ] Ручка текущего пользователя отдаёт логин, имя и группы
- [ ] `docs/entities.md` и контракт описывают новые поля

## Тест-кейсы

1. Решение с `Remote-User: ivan`, `Remote-Name: Иван`: в карточке группы автор решения Иван.
2. Решение без `Remote-User`: 401, статус группы не изменился.
