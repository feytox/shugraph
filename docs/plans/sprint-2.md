# План спринта 2 (01.11-30.11)

## Цель

Одна мошенническая схема проходит весь путь на prod:

1. Запускаем сценарий из Swagger graph-admin-api.
2. В списке появляется новая группа.
3. Открываем её граф и карточку с причинами риска.
4. Подтверждаем или отклоняем группу.

Это первые два критерия приёмки из [ТЗ](../tz.md), их и покажем экспертам в конце ноября. Схему выбирает @BarminGeorge.

## Как работаем

- Обязательное должно успеваться даже при медленном темпе. Запас берём, только когда оно готово
- Вместо дедлайнов на пятничной летучке сверяем контрольные точки и перераспределяем работу, если нужно
- Задачи на 1-3 дня, каждая сразу в `main` отдельным PR. Долгих фича-веток больше нет: на ревью экспертам отправляем либо уже закрытые PR, либо `main`
