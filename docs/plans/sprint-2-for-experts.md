# План на ноябрь

## Что есть сейчас

- Описаны четыре мошеннические схемы, правила их обнаружения и расчёт риска группы.
- Есть каркасы бэкенда (сервис обнаружения групп и сервис запуска тестовых сценариев) и фронтенда. Пока они только поднимаются и ничего не находят.
- Есть виртуалка в Yandex Cloud под prod.

## Что будет к концу ноября

Одна схема проходит весь путь на prod:

1. Запускаем тестовый сценарий: поток входов и переводов со встроенной схемой.
2. Бэкенд находит группу, и она появляется в списке на фронтенде.
3. Аналитик открывает граф группы и карточку с причинами риска.
4. Подтверждает или отклоняет группу.

Для остальных трёх схем к концу ноября будут готовы тестовые сценарии и тексты карточек, а находить их бэкенд начнёт в следующих этапах.

## По неделям

- до 08.11: настраиваем деплой на prod, пока там каркасы;
- до 15.11: бэкенд принимает события и находит группы, на фронтенде список групп на моках;
- до 22.11: на фронтенде граф группы и карточка с решением, тоже на моках; API бэкенда отдаёт настоящие группы;
- до 29.11: фронтенд переходит с моков на API бэкенда, проверяем весь путь на prod.

Если фронтенд не успеет перейти на API, покажем его на моках, а бэкенд отдельно.

## Что не входит

- Обнаружение остальных схем, фильтры в списке групп.
- Авторизация: сделаем до публичной защиты.
