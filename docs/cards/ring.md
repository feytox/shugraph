# Карточка расследования: «Кольцо»

Шаблон текста карточки для [Ф5](../features.md#ф5-карточка-расследования), схема «кольцо» (`scheme: ring`).

Фронт собирает объяснение из `risk_parts.ring` и `features` группы, которые приходят в ответе graph-api.

## Данные для сборки

| Что | Откуда в ответе API | Пример |
|---|---|---|
| Уровень риска | `risk_level` | `high` |
| Итоговый риск | `risk_score` | `85` |
| Слагаемые риска | `risk_parts.ring` | `{"scheme": 65, "speed": 10, "rounds": 0, "accounts": 0, "preserved": 10}` |
| Длительность | `features.span_minutes` | `57` |
| Число счетов | `features.accounts_count` | `3` |
| Оборот | `features.total_amount`, копейки | `59000000` |
| Число кругов | `transfers` группы, количество полных кругов | `2` |
| Счетов в кольце | число уникальных счетов в контуре кольца | `3` |
| Доля возврата | отношение суммы последних переводов к первым по кругам, % | `97` |

`risk_parts.ring` содержит баллы, а не исходные количества: `rounds` — баллы за число кругов, `accounts` — баллы за число счетов в кольце, `preserved` — баллы за долю вернувшейся суммы.

`rounds_count` — число завершённых кругов в кольце (засчитывается круг с возвратом не менее 90%).
`accounts_in_ring` — количество уникальных счетов в контуре кольца.
`preserved_percent` — процент вернувшейся суммы: `floor(сумма последних переводов засчитанных кругов * 100 / сумма первых переводов тех же кругов)`. В схеме кольца входы в кабинет не участвуют — схема выявляется исключительно по переводам.

Подписи уровня риска:

| `risk_level` | Подпись |
|---|---|
| `low` | низкий |
| `medium` | средний |
| `high` | высокий |

## Слагаемые риска

| Слагаемое из [risk.md](../schemes/risk.md) | Плейсхолдер в шаблоне | Что подставляем | Формулировка |
|---|---|---|---|
| Тип схемы «кольцо» | `scheme_line` | `risk_parts.ring.scheme` | `Тип схемы «кольцо»: +{scheme}.` |
| Скорость | `speed_line` | `features.span_minutes`, `risk_parts.ring.speed` | `Скорость: {span_minutes} мин от первого до последнего события — +{speed}.` |
| Число кругов | `rounds_line` | `rounds_count`, `risk_parts.ring.rounds` | `Кругов в кольце: {rounds_count} — +{rounds}.` |
| Счетов в кольце | `accounts_line` | `accounts_in_ring`, `risk_parts.ring.accounts` | `Счетов в кольце: {accounts_in_ring} — +{accounts}.` |
| Доля возврата | `preserved_line` | `preserved_percent`, `risk_parts.ring.preserved` | `Вернулось на стартовый счёт: {preserved_percent}% — +{preserved}.` |

Строки обоснования собираются по таблице; шаблон только подставляет соответствующие плейсхолдеры. `risk_parts.ring.rounds`, `accounts` и `preserved` — баллы по [risk.md](../schemes/risk.md); в тексте подставляем фактические `rounds_count`, `accounts_in_ring` и `preserved_percent`.

Итог берётся из `risk_score`; для схемы сумма слагаемых не превышает 100, поэтому совпадает с итогом.

## Шаблон текста

```text
Риск: {risk_level_label} ({risk_score}/100)
Счетов в группе: {accounts_count}, оборот: {total_amount_rub} ₽.

Что произошло:
{scheme_summary}

Обоснование риска:
- {scheme_line}
- {speed_line}
- {rounds_line}
- {accounts_line}
- {preserved_line}

Итого: {risk_score}/100 — {risk_level_label}.
```

`total_amount_rub` — `features.total_amount / 100`, целые рубли с разделителем разрядов.

`scheme_summary` — короткое объяснение схемы простыми словами:

`Деньги перемещались по замкнутому кругу между счетами участников (всего {accounts_in_ring} счёта) и вернулись на стартовый счёт, причём круг повторился {rounds_count} раза (вернулось {preserved_percent}% суммы). Это признак циклической схемы: деньги гоняют по кругу между своими, чтобы создать видимость оборота в выписке или запутать след транзакций.`


## Сценарий `ring`

Сценарий: [`backend/graph-admin-api/scenarios/ring.json`](../../backend/graph-admin-api/scenarios/ring.json). После запуска группа должна прийти с такими полями:

| Поле | Значение |
|---|---|
| `scheme` | `ring` |
| `risk_score` | `85` |
| `risk_level` | `high` |
| `risk_parts.ring` | `{"scheme": 65, "speed": 10, "rounds": 0, "accounts": 0, "preserved": 10}` |
| `features.span_minutes` | `57` |
| `features.accounts_count` | `3` |
| `features.total_amount` | `59000000` |
| `rounds_count` | `2` |
| `accounts_in_ring` | `3` |
| `preserved_percent` | `97` |

Проверка чисел: `65 + 10 + 0 + 0 + 10 = 85`, уровень `high` — диапазон 75–100. `span_minutes` — 57 минут (20:00–20:57), `total_amount` — 59 000 000 копеек (100 000 + 98 000 + 97 000 + 100 000 + 98 000 + 97 000 ₽). `accounts_count` — 3 счёта, `rounds_count` — 2 круга, `accounts_in_ring` — 3 счёта, `preserved_percent` — 97% ((97 000 + 97 000) * 100 / (100 000 + 100 000) = 194 000 / 200 000 = 97%).

Ожидаемый текст карточки:

```text
Риск: высокий (85/100)
Счетов в группе: 3, оборот: 590 000 ₽.

Что произошло:
Деньги перемещались по замкнутому кругу между счетами участников (всего 3 счёта) и вернулись на стартовый счёт, причём круг повторился 2 раза (вернулось 97% суммы). Это признак циклической схемы: деньги гоняют по кругу между своими, чтобы создать видимость оборота в выписке или запутать след транзакций.

Обоснование риска:
- Тип схемы «кольцо»: +65.
- Скорость: 57 мин от первого до последнего события — +10.
- Кругов в кольце: 2 — +0.
- Счетов в кольце: 3 — +0.
- Вернулось на стартовый счёт: 97% — +10.

Итого: 85/100 — высокий.
```
