# Карточка расследования: «Одно устройство на толпу»

Тексты и правила формирования карточки для [Ф5](../features.md#ф5-карточка-расследования), схема «ферма» (`scheme: farm`). Общий шаблон карточки и общие поля описаны в [README.md](README.md).

## Специфичные данные схемы

| Что | Откуда в ответе API | Пример |
|---|---|---|
| Слагаемые риска | `risk_parts.farm` | `{"scheme": 50, "speed": 15, "clients": 0, "collector": 10}` |
| Число клиентов | `logins` группы, уникальные `client_id` | `3` |

`risk_parts.farm` содержит баллы: `clients` — баллы за число клиентов, `collector` — баллы за наличие общего счёта.
`clients_count` — число различных `client_id` в `logins` группы (уникальные клиенты из входов).

## Слагаемые риска

| Слагаемое из [risk.md](../schemes/risk.md) | Плейсхолдер | Что подставляем | Формулировка |
|---|---|---|---|
| Тип схемы «ферма» | `scheme_line` | `risk_parts.farm.scheme` | `Тип схемы «ферма»: +{scheme}.` |
| Число клиентов | `clients_line` | `clients_count`, `risk_parts.farm.clients` | `Клиентов на одном устройстве: {clients_count} — +{clients}.` |
| Общий счёт для вывода | `collector_line` | `risk_parts.farm.collector` | при `collector > 0`: `Есть общий счёт для вывода денег: +{collector}.`; при `collector == 0`: `Общего счёта для вывода денег нет: +0.` |

Строка скорости (`speed_line`) формируется по [общим правилам](README.md#общие-слагаемые-риска).

Состав строк «Обоснование риска» для фермы:
- `{scheme_line}`
- `{speed_line}`
- `{clients_line}`
- `{collector_line}`

## Формулировки `scheme_summary`

- при `collector > 0`: `С одного устройства заходили в личный кабинет разные клиенты (всего {clients_count}). Деньги с их счетов ушли на общий счёт для вывода — вероятный сборщик. Это признак фермы: возможно, за разными счетами стоит один организатор, который работает с одного устройства и собирает деньги на своём счёте.`
- при `collector == 0`: `С одного устройства заходили в личный кабинет разные клиенты (всего {clients_count}). Общего счёта для вывода не видно, но несколько клиентов на одном устройстве — уже признак фермы: возможно, счетами управляет один человек.`

## Сценарий `device_farm_with_group`

Сценарий: [`backend/graph-admin-api/scenarios/device_farm.json`](../../backend/graph-admin-api/scenarios/device_farm.json). После запуска группа должна прийти с такими полями:

| Поле | Значение |
|---|---|
| `scheme` | `farm` |
| `risk_score` | `75` |
| `risk_level` | `high` |
| `risk_parts.farm` | `{"scheme": 50, "speed": 15, "clients": 0, "collector": 10}` |
| `features.span_minutes` | `28` |
| `features.accounts_count` | `4` |
| `features.total_amount` | `16100000` |
| `clients_count` | `3` |

Проверка чисел: `50 + 15 + 0 + 10 = 75`, уровень `high` — диапазон 75–100. `span_minutes` — 28 минут (10:01–10:29), `total_amount` — 16 100 000 копеек (52 000 + 42 000 + 67 000 ₽). `accounts_count` — 4 счёта, `clients_count` — 3 различных `client_id` в `logins`.

Ожидаемый текст карточки:

```text
Риск: высокий (75/100)
Счетов в группе: 4, оборот: 161 000 ₽.

Что произошло:
С одного устройства заходили в личный кабинет разные клиенты (всего 3). Деньги с их счетов ушли на общий счёт для вывода — вероятный сборщик. Это признак фермы: возможно, за разными счетами стоит один организатор, который работает с одного устройства и собирает деньги на своём счёте.

Обоснование риска:
- Тип схемы «ферма»: +50.
- Скорость: 28 мин от первого до последнего события — +15.
- Клиентов на одном устройстве: 3 — +0.
- Есть общий счёт для вывода денег: +10.

Итого: 75/100 — высокий.
```
