# Карточки расследования

Общий шаблон и правила формирования текста карточки расследования для [Ф5](../features.md#ф5-карточка-расследования).

Фронт собирает объяснение из полей группы, которые приходят в ответе graph-api: общих признаков (`features`), итогового риска (`risk_level`, `risk_score`) и слагаемых формулы риска (`risk_parts`). Точные формулировки слагаемых и эталонные тексты сценариев вынесены в отдельные документы по схемам.

## Документы по схемам

- [device-farm.md](device-farm.md) — схема 1: «Одно устройство на толпу» (`scheme: farm`)
- [shared-address.md](shared-address.md) — схема 2: «Один адрес на толпу» (`scheme: address`)
- [fast-chain.md](fast-chain.md) — схема 3: «Быстрая цепочка» (`scheme: chain`)
- [ring.md](ring.md) — схема 4: «Кольцо» (`scheme: ring`)

## Общие данные для сборки

| Что | Откуда в ответе API | Пример |
|---|---|---|
| Уровень риска | `risk_level` | `high` |
| Итоговый риск | `risk_score` | `75` |
| Длительность | `features.span_minutes` | `28` |
| Число счетов | `features.accounts_count` | `4` |
| Оборот | `features.total_amount`, копейки | `16100000` |
| Слагаемые риска | `risk_parts.<scheme>` | объект с баллами по схеме |

Подписи уровня риска (`risk_level_label`):

| `risk_level` | Подпись |
|---|---|
| `low` | низкий |
| `medium` | средний |
| `high` | высокий |

`total_amount_rub` — `features.total_amount / 100`, целые рубли с разделителем разрядов (например, `161 000`).

## Общий шаблон текста

```text
Риск: {risk_level_label} ({risk_score}/100)
Счетов в группе: {accounts_count}, оборот: {total_amount_rub} ₽.

Что произошло:
{scheme_summary}

Обоснование риска:
- {scheme_line}
- {speed_line}
{scheme_specific_reasons}

Итого: {risk_score}/100 — {risk_level_label}.
```

## Общие слагаемые риска

Строка обоснования скорости (`speed_line`) формируется одинаково для всех 4 схем:

| Слагаемое из [risk.md](../schemes/risk.md) | Плейсхолдер | Что подставляем | Формулировка |
|---|---|---|---|
| Скорость | `speed_line` | `features.span_minutes`, `risk_parts.<scheme>.speed` | `Скорость: {span_minutes} мин от первого до последнего события — +{speed}.` |

Строки обоснования собираются по таблицам; шаблон подставляет соответствующие плейсхолдеры. Итог берётся из `risk_score` (не более 100).

Специфичные слагаемые, подстановка исходных количеств и тексты `{scheme_summary}` описаны в документах схем.
