# Подсчет рисков

## Как считается

```text
риск = минимум(100, тип схемы + скорость + масштаб)
```

Уровни риска:

| Уровень | Диапазон |
|---|---|
| низкий | 0–59 |
| средний | 60–74 |
| высокий | 75–100 |

## Тип и скорость

Тип:

| Тип | Баллы |
|---|---|
| ферма | 50 |
| адрес | 40 |
| цепочка | 55 |
| кольцо | 65 |

Скорость (для всех схем одинаковая). `span` — время от первого до последнего события группы:

| span | Бонус |
|---|---|
| до 10 мин | +20 |
| 11–30 мин | +15 |
| 31–60 мин | +10 |
| 61–180 мин | +5 |
| больше 3 часов | +0 |

`span` считаем в целых минутах, дробь отбрасываем.

Примечание: `span` считается по всей группе, от первого до последнего события, поэтому опоздавшее событие снижает бонус: два круга за 2 минуты дают +20, а третий круг через 20 часов растянет `span` и обнулит бонус. Риск пересчитывается при каждом дополнении группы, пока она не заморожена. Затухание скорости от таких хвостов — известное ограничение MVP.

## 1. Одно устройство на толпу

Минимум: 3 разных клиента с одного устройства за 24 часа.

Масштаб:

| Клиентов | Баллы |
|---|---|
| 3 | +0 |
| 4 | +5 |
| 5 | +10 |
| 6 и больше | +15 |

| Общий счет куда переводят деньги (сборщик)| Баллы |
|---|---|
| есть | +10 |
| нет | +0 |

Пример:

```mermaid
flowchart LR
    C1((Равиль)) --> A1[счёт Равиля]
    C2((Саша)) --> A2[счёт Саши]
    C3((Дима)) --> A3[счёт Димы]
    A1 -.-> D([одно устройство])
    A2 -.-> D
    A3 -.-> D
    A1 ==>|52 000| S[сборщик]
    A2 ==>|52 000| S
    A3 ==>|67 000| S
```

Как сложился риск:

```mermaid
flowchart LR
    B["Тип ферма: 50"] --> S["Скорость 28 мин: +15"] --> C["3 клиента: +0"] --> H["Есть сборщик: +10"] --> T["Итого 75 — высокий"]
```

## 2. Общий адрес

Минимум: 4+ счетов заходили с одного адреса за 24 часа + устройства разные (2+ разных) + деньги ушли на общий счёт вывода. Плюс кучность по времени: у каждого счёта берём его самый ранний вход в окне и все эти первые входы должны уложиться в 60 минут.

Масштаб:

| Счетов | Баллы |
|---|---|
| 4 | +0 |
| 5–6 | +10 |
| 7+ | +15 |

| Устройств | Баллы |
|---|---|
| 2 | +0 |
| 3–4 | +5 |
| 5+ | +10 |

| Кучность первых входов | Баллы |
|---|---|
| до 10 мин | +10 |
| 11–30 мин | +5 |
| 31–60 мин | +0 |

Кучность считаем в целых минутах, дробь отбрасываем.

Пример:

```mermaid
flowchart LR
    A1[счёт Анны] -. 18:00 .-> D1([устройство 1])
    A2[счёт Бориса] -. 18:04 .-> D2([устройство 2])
    A3[счёт Веры] -. 18:07 .-> D3([устройство 3])
    A4[счёт Вовы] -. 18:10 .-> D3
    A1 -.-> IP{{один адрес}}
    A2 -.-> IP
    A3 -.-> IP
    A4 -.-> IP
    A1 ==>|18:25| OUT1[вывод 1]
    A2 ==>|18:30| OUT1
    A3 ==>|18:35| OUT2[вывод 2]
    A4 ==>|18:40| OUT2
```

Как сложился риск:

```mermaid
flowchart LR
    B["Тип адрес: 40"] --> S["Скорость 40 мин: +10"] --> C["4 счёта: +0"] --> D["3 устройства: +5"] --> K["Кучность 10 мин: +10"] --> T["Итого 65 — средний"]
```

## 3. Цепочка

Минимум: 3+ переводов подряд, всё за 60 минут, до конца дошло 90%+ первой суммы.

Масштаб:

| Переводов (хопов) | Баллы |
|---|---|
| 3 | +0 |
| 4 | +10 |
| 5+ | +15 |

Сколько дошло (`сумма последнего перевода * 100 / сумма первого перевода`, дробь отбрасываем; больше 100 считаем за 100):

| Дошло | Баллы |
|---|---|
| 90–92% | +0 |
| 93–95% | +5 |
| 96–98% | +10 |
| 99–100% | +15 |

Пример:

```mermaid
flowchart LR
    A[счёт Олега] ==>|18:03<br/>83 500| B[счёт Игоря]
    B ==>|18:07<br/>82 000| V[счёт Павла]
    V ==>|18:11<br/>80 000| G[счёт Романа]
    G ==>|18:14<br/>79 000| D[счёт Тимура]
```

Как сложился риск:

```mermaid
flowchart LR
    B["Тип цепочка: 55"] --> S["Скорость 11 мин: +15"] --> H["4 перевода: +10"] --> K["Дошло 94%: +5"] --> T["Итого 85 — высокий"]
```

## 4. Кольцо

Минимум: круг из 3–5 счетов + 2+ полных круга за 24 часа.

Масштаб:

| Кругов | Баллы |
|---|---|
| 2 | +0 |
| 3 | +10 |
| 4+ | +15 |

| Счетов в кольце | Баллы |
|---|---|
| 3 | +0 |
| 4 | +5 |
| 5 | +10 |

Сколько вернулось (`сумма последних переводов засчитанных кругов * 100 / сумма первых переводов тех же кругов`, дробь отбрасываем; засчитанный круг — возврат ≥90%):

| Вернулось | Баллы |
|---|---|
| 90–92% | +0 |
| 93–95% | +5 |
| 96–98% | +10 |
| >=99% | +15 |

Пример:

```mermaid
flowchart LR
    A[счёт Артёма] ==>|круг 1<br/>100 000| B[счёт Богдана]
    B ==>|круг 1<br/>98 000| V[счёт Влада]
    V ==>|круг 1<br/>97 000| A
    A ==>|круг 2<br/>100 000| B
    B ==>|круг 2<br/>98 000| V
    V ==>|круг 2<br/>97 000| A
```

Как сложился риск:

```mermaid
flowchart LR
    B["Тип кольцо: 65"] --> S["Скорость 57 мин: +10"] --> R["2 круга: +0"] --> C["3 счёта: +0"] --> K["Вернулось 97%: +10"] --> T["Итого 85 — высокий"]
```
