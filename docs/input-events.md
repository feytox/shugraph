# Входные события сценариев

События, которые задаются в сценариях и передаются генератором (`graph-admin-api`) в ядро системы (`graph-api`).

---

## Общие поля

Есть у каждого события.

| Поле | Тип | Описание |
|---|---|---|
| `event_id` | string | номер события от источника, ключ дедупликации |
| `type` | enum: `transfer` / `login` | тип события |
| `occurred_at` | timestamp (ISO 8601, UTC) | время совершения операции или входа |

---

## 1. Перевод (`transfer`)

Общие поля + поля ниже.

| Поле | Тип | Описание |
|---|---|---|
| `from_account_id` | string | счёт отправителя |
| `from_client_id` | string | владелец счёта отправителя |
| `to_account_id` | string | счёт получателя |
| `to_client_id` | string | владелец счёта получателя |
| `amount` | integer | сумма перевода в копейках |

---

## 2. Вход (`login`)

Общие поля + поля ниже.

| Поле | Тип | Описание |
|---|---|---|
| `account_id` | string | счёт |
| `client_id` | string | владелец счёта |
| `device_id` | string | отпечаток устройства |
| `address_id` | string | сетевой адрес (IP) |
