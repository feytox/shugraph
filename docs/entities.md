# Сущности

## Клиенты (`clients`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `id` | string | из события (владелец счёта) |

## Счета (`accounts`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `id` | string | из события (номер счёта отправителя/получателя, счёт входа) |
| `client_id` | string | из события (владелец счёта) |

## Устройства (`devices`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `device_id` | string | из события входа |

## Сетевые адреса (`network_addresses`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `ip` | string | из события входа |

## События (`events`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `event_id` | string | из события (номер от источника, задаётся в сценарии) |
| `type` | enum: перевод / вход | из события |
| `occurred_at` | timestamp | из события (время события) |

## Переводы (`transfers`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `event_id` | string | из события (тот же id) |
| `from_account_id` | string | из события (счёт отправителя) |
| `to_account_id` | string | из события (счёт получателя) |
| `amount` | money | из события (сумма) |

## События входа (`login_events`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `event_id` | string | из события |
| `account_id` | string | из события (счёт и владелец) |
| `client_id` | string | из владельца счёта на момент приёма |
| `device_id` | string | из события (отпечаток) |
| `address_id` | string | из события (IP) |

## Группы (`groups`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `id` | uuid | системное |
| `scheme` | enum: ферма / адрес / цепочка / кольцо |
| `status` | enum: новая / подтверждена / отклонена |
| `risk_score` | integer (0–100) |
| `first_event_at` | timestamp | вычисляется в приложении на основе событий |
| `last_event_at` | timestamp | вычисляется в приложении на основе событий |
| `is_frozen` | boolean | решение аналитика или события вышли из окна |
| `decision_comment` | string | действие аналитика |

## Участник группы (`group_members`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `group_id` | uuid | вычисление |
| `account_id` | string | вычисление |

## Доказательства группы (`group_events`)

| Поле | Тип | Откуда берётся |
|---|---|---|
| `group_id` | uuid | вычисление |
| `event_id` | string | вычисление |

## Признаки группы (`group_features`)

Общие для всех групп:

| Поле | Тип | Откуда берётся |
|---|---|---|
| `group_id` | uuid | вычисление |
| `accounts_count` | integer | вычисление |
| `events_count` | integer | вычисление |
| `span_minutes` | integer | вычисление |
| `total_amount` | money | вычисление |

Только для типов:

| Поле | Тип | Откуда берётся |
|---|---|---|
| `hops_count` | integer | вычисление (цепочка, кольцо) |
| `rounds_count` | integer | вычисление (кольцо) |
| `first_amount` | money | вычисление (цепочка) |
| `last_amount` | money | вычисление (цепочка) |
