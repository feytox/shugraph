### Задача
Договариваемся о формате ответов до кода, чтобы фронт верстал на моках, а бэк писал ручки параллельно.

## Решение

- [ ] OpenAPI-спека graph-api в репо:
  - [x] приём событий 
  - [x] список гипотез 
  - [x] одна гипотеза
  - [ ] подграф гипотезы
  - [x] решение по гипотезе
- [ ] формат графа выбран под библиотеку отрисовки из [GSD-15](https://shu42.youtrack.cloud/issue/GSD-15/Resyorch-biblioteki-otrisovki-grafa)
- [x] пагинация списка гипотез
- [ ] моки на фронте генерируются из спеки

Тут ещё стоит выбрать: пишем сначала OpenAPI или сразу мокаем на бэке и генерим спеку по нему.
